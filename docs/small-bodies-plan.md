# 小天体星历方案

ClearskyGoto 的小天体功能服务于晴空谐波赤道仪的现场目视寻星和 GOTO 辅助。目标是按需添加常见小行星和彗星，而不是内置完整 MPC 数据库。

## 当前实现

- 内置少量常见小行星和彗星作为离线基线。
- 用户可在 App 内按名称添加小行星或彗星。
- 数据来源为 JPL SBDB。
- 用户添加的数据保存到 App 私有目录，并在同名时覆盖内置基线。
- 星图图层可独立显示小行星和彗星。

## 为什么不内置完整数据库

完整小行星数据库体积大、更新频繁，且多数目标对目视用户不可见。对晴空谐波赤道仪的现场控制来说，更合适的策略是：

1. 内置少量经典目标，保证离线演示和基础使用。
2. 用户观测前按名称添加目标，保证目标元素尽量新。
3. 日志记录下载过程，便于定位 SBDB 查询、解析和显示问题。

## 支持的目标类型

| 类型 | 说明 |
| --- | --- |
| 小行星 | 编号小行星、命名小行星 |
| 周期彗星 | 例如 `1P/Halley`、`2P/Encke` |
| 非编号彗星 | 例如 `C/2023 A3` |
| 近抛物/双曲轨道 | 支持 e 接近或大于 1 的彗星轨道传播 |

## 查询与解析规则

- 用户输入为空时不关闭对话框，并提示继续输入。
- JPL 返回 HTTP 300 多候选时，按目标类型过滤候选。
- 彗星候选同时检查 `pdes` 和 `name`，避免非编号彗星漏识别。
- 单体响应读取 `object.des`、`object.prefix` 和 `object.kind`，组合标准 IAU designation。
- `object.kind` 与用户选择类型不一致时拒绝写入。
- 同名目标按 designation + kind 合并，用户数据覆盖内置数据。

## 轨道传播

小天体使用二体 Keplerian 传播：

- 椭圆轨道：解 `E - e sin(E) = M`。
- 近抛物轨道：使用 Barker 方程。
- 双曲轨道：解 `M = e sinh(F) - F`。

随后转换到地心视位置链路，用于星图显示和 GOTO 坐标。

## 精度边界

小天体元素受摄动、观测弧长和数据新鲜度影响明显。当前实现适合：

- 目视寻星参考。
- 低到中等倍率 GOTO 辅助。
- 在星图中确认目标大致方位。

不适合：

- 掩星预报。
- 精密测量。
- 长时间不更新元素后寻找暗弱彗星。

彗星亮度尤其不稳定，实际可见性可能与预测星等相差很大。

## 测试建议

1. 添加 `Ceres`，确认小行星图层可见。
2. 添加 `Halley`，确认不会误命中同名小行星。
3. 添加 `C/2023 A3`，确认 designation 保留完整前缀。
4. 切换图层，确认小行星和彗星可独立显示。
5. 搜索已添加目标，确认星图可定位并生成 GOTO 目标。
6. 断网后重启 App，确认用户添加目标仍保留。

## 后续可改进

- 增加用户可见的“数据时间/元素历元”提示。
- 为小天体添加单独的删除入口。
- 对过期彗星元素给出更明显警告。
- 在日志中记录 SBDB 查询 URL、候选解析和最终 designation。
