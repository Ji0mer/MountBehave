# ClearskyGoto 测试人员指南

适用版本：`0.2.5` 及当前 `ClearskyGoto` 分支开发版。

ClearskyGoto 是针对晴空谐波赤道仪现场使用开发的 Android 控制 App，代码基础来自 MountBehave `v0.2.5`。本文帮助测试人员完成安装、连接、星图 GOTO、支架校准、日志导出和问题反馈。

## 1. 测试前安全检查

测试前请确认：

1. 赤道仪、三脚架、镜筒、配重和线缆已经可靠固定。
2. 镜筒转动路径内没有人、墙体、三脚架腿、电脑线、供电线或其他障碍物。
3. 已经知道实体断电、控制盒急停或赤道仪原控制器停止运动的方法。
4. 初次测试使用低速或中速移动，不直接使用最高速。
5. 夜间测试前，先在白天或室内空载熟悉界面和停止按钮。
6. 不把当前版本用于无人值守、远程无人看护或高风险自动化控制。

App 内“停止”是辅助安全手段，不能替代实体安全措施。

## 2. 准备工作

测试人员需要准备：

- Android 手机或平板，建议 Android 8.0 或更新。
- ClearskyGoto APK。
- 晴空谐波赤道仪及其 WiFi 控制信息。
- 观测地经纬度，或允许手机使用定位权限。
- 可发送日志的方式，例如 QQ、微信、邮箱或电脑 USB 文件传输。

建议记录：

- 手机/平板型号与 Android 版本。
- 赤道仪型号。
- 固件类型：OnStep 或 OnStepX。
- 支架模式：赤道仪或经纬仪。
- 测试地点大致区域。

## 3. 安装 APK

通过 Android 文件管理器打开 APK，允许当前应用安装未知来源应用，然后完成安装。

通过 ADB 安装：

```powershell
adb install -r app-debug.apk
```

`-r` 表示覆盖安装，通常保留 App 数据。需要干净测试时，请在 Android 系统设置中清除 ClearskyGoto 应用数据。

## 4. 首次设置

打开 App 后先进入“设置”页：

1. 选择固件类型：默认 OnStep；使用 OnStepX 时选择 OnStepX。
2. OnStepX 下选择支架类型：赤道仪或经纬仪。
3. 确认语言：默认中文，可切换英文。
4. 保持命令日志开启，便于现场反馈。

切换 OnStepX 支架类型会写入控制器配置。写入成功后 App 会断开连接，用户需要重启控制器后再连接。

## 5. 连接晴空赤道仪

1. 在 Android 系统 WiFi 设置中连接赤道仪 WiFi。
2. 如果系统提示“此 WiFi 无互联网”，选择保持连接。
3. 回到 ClearskyGoto，进入“连接/同步”页。
4. 确认 IP 和端口，默认：

```text
192.168.0.1
9999
```

5. 点击连接按钮。
6. 成功后页面应显示已连接状态。

如果连接失败，请检查手机是否自动切回了其他 WiFi 或移动数据。

## 6. 同步观测地和时间

推荐连接后先同步站点信息：

1. 进入“连接/同步”页。
2. 点击标题右侧的 GPS 图标，或手动输入纬度、经度、日期和时间。
3. 点击同步图标，将时间和地点写入赤道仪。

如果手动修改过日期或时间，App 会在同步前询问使用系统当前时间还是输入框时间，避免把星图演示时间误写入赤道仪。

## 7. 跟踪控制

“连接/同步”页的连接卡片里包含跟踪速率：

- 恒星速
- 月球速
- 太阳速

默认恒星速。经纬仪模式下启动跟踪时使用双轴跟踪语义，让设备按所选速率保持目标。

## 8. 星图页面

星图页面集成了星图、GOTO、同步、方向控制盘和支架校准。

基本操作：

- 单指拖拽星图：移动视野。
- 双指缩放：改变视场。
- 点击时间：设置星图日期和时间。
- 点击“移动”：显示或隐藏方向控制盘。
- 点击速率文字：选择移动速率，默认 `20x`。
- 点击右侧搜索图标：搜索目标。
- 点击右侧图层图标：切换星座线、太阳系、小行星、彗星等图层。

执行 GOTO、同步或校准等会移动赤道仪的操作前，App 会自动把星图时间恢复为当前时间，避免把历史/未来时刻的动态天体坐标发给真实设备。

## 9. GOTO 测试

初次测试请选择中高空亮星，不要从低空、近天极、线缆风险区或机械限位附近目标开始。

流程：

1. 确认赤道仪已连接且未停放。
2. 在星图中点选目标，或用搜索输入名称/坐标。
3. 点击 GOTO。
4. 观察状态信息中的 GOTO 状态。
5. GOTO 进行中可点击取消。
6. 到位后，若目标不在中心，显示方向控制盘并低速居中。
7. 点击同步，建立当前位置修正。

如果提示“需手控恢复”或出现限位/硬件错误，请停止继续 GOTO，先用低速手控移出危险位置并导出日志。

## 10. 支架校准

点击星图右侧的校准图标可展开支架校准面板。收起面板不会取消正在进行的校准流程。

两星/三星校准：

1. 选择校准模式。
2. 点击开始校准。
3. 设置当前校准目标。
4. 用方向控制盘居中目标。
5. 点击居中后同步。
6. 对后续校准星重复设置目标和居中同步。
7. 最后一颗星接受后，App 自动保存模型。

选星建议：

- 使用容易识别的亮星。
- 高度角尽量高于 25°。
- 不要全部选在同一小片天区。
- 初次测试不要选择极区或机械风险区目标。

极轴精调：

- 仅赤道仪模式显示。
- 需要先完成三星或更多星模型。
- 两星模型只用于 GOTO / 跟踪补偿，不解锁 Refine PA。

## 11. 停止与停放

- 左侧悬浮“停止”按钮始终显示。
- Park 状态下，常规 GOTO、同步、跟踪和方向控制会禁用。
- 停放按钮是状态机：未停放时执行停放，已停放时执行解除停放。
- 停止按钮不能替代实体断电或控制器急停。

## 12. 小天体

设置页“太阳系天体星历”可添加小行星和彗星。在线添加使用 JPL SBDB，需要手机有互联网。

如果手机正连接赤道仪 WiFi 且该 WiFi 无互联网，可能需要临时切换网络后再添加小天体。

小天体位置适合目视寻星参考，不适合掩星预报或精密测量。

## 13. 日志导出

出现问题后请先导出日志：

1. 进入“设置”页底部“命令日志”。
2. 确认记录日志已开启。
3. 点击导出日志。
4. 选择保存到下载目录或分享。

反馈时请附上日志，并说明：

```text
App 版本：
手机/平板型号：
Android 版本：
赤道仪型号：
固件类型：
支架模式：
连接 IP/端口：
发生时间：
操作步骤：
目标名称或坐标：
App 显示状态：
赤道仪实际动作：
是否点击过停止/取消/断开：
附件：导出的日志
```

## 14. 建议测试清单

1. 安装 APK 并打开 App。
2. 切换语言并重启 App，确认语言保存。
3. 连接赤道仪 WiFi。
4. App 内连接默认 IP/端口。
5. 同步 GPS 或手动站点信息。
6. 测试显示/隐藏方向控制盘。
7. 测试四方向移动、松手停止和悬浮停止。
8. 星图选择亮星并 GOTO。
9. GOTO 后手动居中并同步。
10. 执行一次两星校准。
11. 如条件允许，执行三星校准和极轴精调。
12. 添加一颗小行星或彗星。
13. 导出日志并确认可发送。

初次测试优先完成连接、停止、GOTO、同步和日志导出。高风险项目应在熟悉设备后再测试。
